# 小说编辑器 MVP 实施路线图

按依赖与风险把 `docs/mvp-spec.md` 切成五个可单独验收的阶段。不写日期或人周。每阶段结束只跑本阶段对应的规格验收句，全部通过再进入下一阶段。领域词以 `CONTEXT.md` 为准，技术约束见 `docs/adr/0001-tauri-tiptap-sqlite.md`。

## 阶段 1：能开能写

作品库、数据包、卷章、Tiptap、约 3 秒自动保存、字数、保存失败拦截、进程单实例。可预埋 SQLite Backup API，**不验收**用户向恢复点。

**完成标准**

- 缺 WebView2 时提示安装，而不是空白崩溃。
- 新建作品能写一章；关掉再打开，章节、光标和滚动位置还在。
- 卷章规则、粘贴清洗、字数「你好，世界 Hello」= 11、保存失败退出拦截，均按规格句走通。

**收口**

代码与本机可复现项已齐：作品库、数据包、FTS5 建表、卷章、Tiptap、约 3 秒自动保存（含开发态 StrictMode 落盘修复）、保存失败拦截、进程单实例。Backup API 已预埋，无用户向恢复点。

仍须人工环境点验：微软拼音 / 搜狗组字不落盘、不跳光标；干净 Win10 22H2（无 WebView2）启动提示安装。第二次启动只唤起已有窗口已在开发机复测。

**验证门（本阶段必须先过）**

- 开工当天：最小 Tiptap 页上用微软拼音 / 搜狗连打，组字过程中不自动保存、不跳光标。
- 建第一张 `work.sqlite` 时确认捆绑 SQLite 能创建 FTS5 表。
- 结束前：干净 Win10 22H2（无 WebView2）启动提示；第二次启动只唤起已有窗口。

## 阶段 2：设定资料

角色、地点、事件、故事线、设定条目、预置分类（含不可删的「未分类」）、地点树、资料进入作品回收站。不做通用关联和总图。

**完成标准**

- 无章节也能建齐五类资料。
- 空名、删除分类后归未分类、故事线移除事件不删事件、删除地点后下级提升，均按规格句走通。

**收口**

代码与本机可复现项已齐：五类设定资料、预置分类（含不可删的「未分类」）、地点无环树与删除后下级提升、故事线收录（移除不删事件）、资料进入作品回收站、阶段 1 作品打开时升到 schema v2。右侧面板查阅不离开写作区。

仍须在桌面端点验：空名显示、删「势力」归未分类、地点下级提升、回收站恢复。浏览器内存库只供对照，不能代替 `npm run tauri dev` 落盘。

## 阶段 3：关联与邻侧查阅

通用关联、本章关联、右侧不离写查阅、`Ctrl+K` 两类结果。

**完成标准**

- 章与角色双向一条；同一对不会出现两条。
- 正文选中文字不建关联、不插入标记。
- 命令面板能跳到章节并高亮，也能打开设定资料且正文仍在。

**验证门**

- 做命令面板前：用两字中文名、别名、章内短句检索。FTS5 trigram 若搜不到 1–2 字，必须有回退，不要假定 trigram 够用。

## 阶段 4：地点总图

一张 png / jpg / webp 底图，单击打点、拖动、事件走线、事件链。

**完成标准**

- 换图只留新图；清图后地点仍在地点树，标记全部消失。
- 走线只连接已定点事件；事件链含未定点事件。

**验证门**

- 往库里写第一个标记前：坐标必须相对底图固有宽高归一化，点击在图像空间计算，显示按 contain 回投。
- 用 100% 与 150% 缩放各拖一次，再换一张不同比例的图打开，标记不漂。

## 阶段 5：保全与带走

恢复点、损坏拒绝、路径失效、作品独占锁、正文导出、`.storyarchive` 导入。然后按 `docs/mvp-spec.md` 全表手工点验。

**完成标准**

- 恢复点在数据包旁，含正文、结构、设定、关联、作品回收站；默认恢复为新作品。
- 损坏包拒绝打开，不写回，不覆盖旁路恢复点。
- 导出 Markdown / 纯文本 / DOCX；归档导入为新身份，允许重名并存。
- 永久删除作品时，旁路恢复点一并消失。断网下可创建恢复点、导出、导入归档。

**验证门**

- 写保留策略之前：自动保存进行中用 Backup API 做恢复点；热拷贝打开中的库必须被否决。
- 作品独占锁：杀进程后锁自动释放，不把作者锁在自己的稿外。
- 接「从恢复点恢复」之前：截断库、缺 WAL 的拷贝、坏 `work.json` 三种夹具均拒绝打开且不写回。
- 做导出界面之前：用 MIT 库从编辑器 JSON 生成含中文标题与基础样式的 DOCX，用 Word 与 WPS 打开。禁止 Tiptap Pro 导出包。

## 明确不这样切

- 不按技术分层（先壳和库、很久不能打字）。
- 不把用户向恢复点验收提前到阶段 1（那时还没有设定与关联）。
- 不写日历或人周。
