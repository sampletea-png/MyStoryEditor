# Triage Labels

The five canonical roles map directly to labels in this repository:

- `needs-triage` → `needs-triage`
- `needs-info` → `needs-info`
- `ready-for-agent` → `ready-for-agent`
- `ready-for-human` → `ready-for-human`
- `wontfix` → `wontfix`

When a skill mentions a canonical role, use the corresponding label string above.
