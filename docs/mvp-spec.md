# 小说编辑器 MVP 规格

个人 Windows 桌面小说编辑器的首版产品规格：功能边界、非功能保证线、手工验收句与明确排除项。领域词以仓库根目录 `CONTEXT.md` 为准。技术选型见 `docs/adr/0001-tauri-tiptap-sqlite.md`。

每条用户可感知能力附一句可手工走通的验收句。自动化测试留给实施，不作为本规格通过条件。

## 产品与运行

- 显示名：**小说编辑器**。
- 平台：Windows 10 22H2 与 Windows 11；单人、本地优先、无需账户。
- 壳层：Tauri 2；界面：React + TypeScript；正文编辑器：Tiptap MIT 核心。
- 外观：单一浅色写作主题；段首缩进为固定表现层，用户不改字体、字号、主题。
- 快捷键：`Ctrl+S` 立即保存；会话内撤销 / 重做；`Ctrl+K` 打开命令面板。
- 首版无自动更新器；不实现 AI 入口或接口。
- 本机当前 Windows 用户视为可信；不做加密、登录或权限隔离。
- 不上传作品内容、恢复点或作品归档；若有崩溃报告，不得附带正文或设定正文。

**验收**

- 在未安装 WebView2 的干净环境启动时，应用提示安装运行时，而不是空白崩溃。
- 断开网络后，仍可打开已有作品、编辑、自动保存、创建恢复点、正文导出、导入作品归档。
- 第二次启动只唤起已有窗口，不出现第二个可写实例。

## 作品库与作品

- 作品库是进入作品的唯一入口；同时只打开一部作品，回作品库才能换作品。
- 默认位置为「文档\小说作品库」；首次启动可改。打开另一作品库只改指向；移动当前作品库时带走作品、恢复点和作品库回收区。
- 每部作品是一份可用资源管理器整夹复制的作品数据包（`work.json` + `work.sqlite` + `assets\`）。
- 作品只有名称；新建时名称必填，随后自动创建并打开「第一章」。无简介、作者、封面。
- 改作品名称不改文件夹名；文件夹名在创建时由名称生成一次，之后稳定。
- 删除作品先进入作品库回收区，可恢复或永久删除；永久删除须警告，并删除该作品全部恢复点。

**验收**

- 首次启动后能指定或确认作品库位置；之后打开应用进入该作品库列表，而不是直接进入某部作品。
- 新建一部名为「北境行纪」的作品后，立即进入写作区，且卷章树中存在「第一章」。
- 将作品数据包文件夹复制到同一作品库下另一位置后，列表中出现可打开的另一部作品（内部身份不同）。
- 将作品改名为「南疆行纪」后，资源管理器中的文件夹名仍是创建时的名字。
- 删除作品后它出现在作品库回收区；永久删除后作品与其旁路恢复点都不再存在，且须经过不可撤销警告。

## 写作与卷章

- 一次只编辑一章。再次打开作品时恢复上次章节、光标和滚动位置。
- 左侧卷章树可新建、重命名、排序、移动、删除卷章。新章节默认插在当前章之后；选中卷时追加到卷末。
- 章节只存自由标题，编号由排列位置推导。卷、章允许重名或空名；空名显示为「未命名卷 / 未命名章节」。
- 卷可选。作品要么直接包含章节，要么由卷包含章节，不混用。创建第一个卷时将已有章节移入；「取消分卷」将所有章节提升到作品下。
- 删除卷会将卷及其中章节整体移入作品回收站；恢复时优先还原原位置，无法还原时追加到最近有效层级。
- 允许作品暂时没有章节；删除最后一章后显示空状态，不自动补建。
- 章节状态为「初稿 / 修订中 / 定稿」。

**验收**

- 打开作品后，上次正在编辑的章节、光标和滚动位置与关闭前一致。
- 在无卷作品中创建第一个卷后，已有章节都在该卷下，且不能再在作品根下直接建章。
- 删除最后一章后，中间编辑区为空状态，不自动出现新的「第一章」。
- 将一章标题清空后，卷章树显示「未命名章节」，该章仍可打开编辑。

## 正文编辑

- 轻量所见即所得：段落、粗体、斜体、删除线、分隔线；当前会话撤销 / 重做。
- 正文保存语义段落。段首缩进不写入正文。`Enter` 新建段落，`Shift+Enter` 插入段内换行。
- 粘贴外部内容只保留受支持的基础格式，并清除字体、字号、颜色；另提供粘贴为纯文本。
- 不导入 TXT / Markdown / DOCX 为章节；已有文字用粘贴。
- 实时显示当前章节和整部作品字数。字数 = 除空白（空格、换行、制表）外的字符，含中英文和标点。
- 保存状态为「保存中 / 已保存 / 保存失败」。正常输入中间隔不超过约 3 秒自动保存；`Ctrl+S` 立即落盘。
- 保存失败时保留内存内容并持续重试；退出或关闭作品前若仍有未落盘内容，必须警告并提供重试或取消，不能静默丢失。

**验收**

- 连续输入正文后停止约 3 秒，状态变为「已保存」，光标与选区不变、无模态框；不经手动保存关闭再打开，该章仍含刚才输入的文字。
- 按 `Enter` 后出现新段落；按 `Shift+Enter` 后仍在同一段落内换行。
- 从网页粘贴带颜色和字号的文字后，编辑器中只留下段落与基础样式，没有原字体颜色。
- 输入「你好，世界 Hello」后，本章字数计为 11（不含空格）。
- 人为让保存失败后，仍可继续打字，状态为「保存失败」；尝试退出时被拦住，不能在未保存成功时默默关掉。

## 设定资料

- 角色、地点、事件、故事线、设定条目只属于一部作品；作品一旦存在即可先建，不要求先有章节。
- 设定分类预置：势力、制度、物种、规则，以及不可删除的「未分类」。用户可增改其他分类；同一作品内分类名不可重复。删除其他分类后，其下设定条目改归未分类。
- 角色：名称、别名（多项）、摘要、外貌、性格、背景。不含数值属性、库存或专用关系字段。
- 地点：名称、摘要、描述；至多一个上级地点，形成无环树。
- 事件：名称、摘要、描述、自由文本故事时间。故事时间不驱动自动排序。
- 故事线：名称、摘要、可排序的事件列表。同一事件在一条故事线中只收录一次。未入线事件仍可独立存在。
- 设定条目：名称、设定分类、摘要、正文。
- 长文本字段使用与正文相同的轻量所见即所得。名称、别名、摘要、故事时间、关联说明、设定分类名为纯文本。
- 名称允许重名或空名。空名显示为「未命名角色 / 未命名地点 / 未命名事件 / 未命名故事线 / 未命名设定」。
- 事件有独立列表，默认可全部看见，可筛「未入任何故事线」。从故事线移除事件只取消收录，不删除事件。
- 各资料列表按名称即时筛选，角色额外匹配别名。
- 设定资料与故事线删除后进入作品回收站，关联或收录一并挂起，恢复后还原。永久删除故事线只丢掉收录，不删事件。删除地点时，下级地点提升到其原上级（无上级则到根）。

**验收**

- 在尚无章节的新作品中可创建角色、地点、事件、故事线和设定条目。
- 将角色名称清空后，右侧资料显示「未命名角色」，该角色仍出现在列表中。
- 删除「势力」分类后，原属该分类的设定条目出现在「未分类」下，且无法删除「未分类」。
- 从故事线移除一个事件后，事件列表中仍能看到该事件。
- 删除一个有下级的地点后，下级出现在其原上级之下（若原地点无上级，则出现在根）。

## 关联

- 结构关系（卷章结构、地点上下级、故事线对事件的有序收录）不走通用关联。
- 通用关联覆盖章节、事件、角色、地点、设定条目任意两两（含同类）。故事线不进入通用关联；其相关章节、角色、地点由其收录的事件汇总。
- 关联不分类型，可写一句可选说明。同一对对象只允许一条，两端顺序不影响同一性。
- 只从章节关联侧栏或资料卡明确建立，支持搜索已有项和「新建并关联」。正文选中文字不建立关联，也不插入可见标记。

**验收**

- 在本章关联中把当前章与一个角色关联后，打开该角色能看到指向该章的同一条关联。
- 对同一对对象再关联一次时被拒绝或视为已存在，不会出现两条。
- 选中正文中的一个词，没有「建立关联」或插入标记的结果。

## 地点总图

- 一部作品至多一张地图图片（png / jpg / webp），可替换、可清除。
- 在总图上单击落下地点标记，可拖动改位置。未打标记的地点只出现在地点树中。
- 选中一条故事线后，总图叠加事件走线：已关联地点的事件按收录顺序编号并连线；未关联地点的事件列在「未定点事件」。多地点事件走线取最先关联的地点。
- 底部事件链按收录顺序列出该故事线全部事件（含未定点事件）。
- 地点之间的其他关系仍走通用关联，不在地图上另画关系线。总图以浮层打开。

**验收**

- 放入一张 jpg 后总图显示该底图；再放入一张 png 后只保留新图。
- 在图上单击可为未定点地点打上标记，拖动后再次打开总图位置仍在。
- 选中一条含已定点与未定点事件的故事线后，走线只连接已定点事件，事件链上两者都在。
- 清除总图后，地点仍在地点树中，标记全部消失。

## 查找与界面

- 默认写作区：左侧可折叠卷章树，中间正文与章节标题 / 状态，右侧本章关联，底部字数与保存状态。
- 查阅角色、地点、事件、故事线、设定条目、作品回收站不离开写作，只替换右侧面板。
- 作品总图以浮层打开。卷章树与本章关联常驻（可折叠）。
- 命令面板（`Ctrl+K`）一个入口、两类结果：章节标题与正文一组，设定资料一组。从章节命中跳转并高亮；从设定命中打开对应右侧资料。

**验收**

- 编辑某一章时，在右侧打开一个角色再切回本章关联，正文仍可继续输入，且未换成另一页。
- 按 `Ctrl+K` 输入正文中独有的一句话，结果出现在章节组，点入后跳到该章并高亮。
- 按 `Ctrl+K` 输入一个角色名，结果出现在设定组，点入后右侧打开该角色，正文仍在。

## 自动保存、恢复点与损坏

- 崩溃后恢复到最后一次成功自动保存；不承诺尚未写入成功的那几秒击键。不把半写入的损坏文件当作当前作品打开。
- 一部作品同时只能被一个实例写入；再次打开提示已在其他窗口打开，不进入可写。
- 数据包被移走、删除或替换时：未保存编辑按保存失败处理；路径失效时提供「重新定位」或从恢复点恢复为新作品，不在原路径静默重建空作品。
- 恢复点是整部作品保全副本（卷章、正文、设定、关联、作品回收站），放在数据包旁，资源管理器可见。触发：退出应用、结构迁移前、每天至少一次、用户手动创建。不内嵌其他恢复点。
- 自动恢复点保留最近 10 个，另保留最近 7 个按日恢复点；手动恢复点不自动删除。
- 默认将恢复点展开为作品库中的新作品。「替换当前作品」须二次确认，且恢复前先为当前作品再做一个恢复点。
- 损坏数据包拒绝作为当前作品打开，提示损坏，提供从最近可用恢复点恢复为新作品；损坏包不自动删除。

**验收**

- 等待自动恢复点条件达成或手动创建一次后，数据包旁出现新的恢复点文件夹；从该恢复点恢复得到一部新作品，正文、结构、设定、关联与打点时刻一致。
- 选择无法读取的损坏数据包时，应用拒绝打开并说明原因，不写回该包，也不覆盖其旁已有恢复点。
- 在已打开作品时再次尝试打开同一数据包，得到「已在其他窗口打开」类提示，第二处不能写入。

## 正文导出与作品归档

- 正文导出：纯文本、Markdown、DOCX。默认按卷章顺序导出整部作品为单个文件（含标题），也可只选部分卷或章。不含设定、事件、关联、章节状态、作品回收站。
- Markdown 为 UTF-8 无 BOM，纯文本为 UTF-8 BOM。卷、章标题写作标题。粗体、斜体、删除线、分隔线在 Markdown 与 DOCX 中保留，在纯文本中去掉格式只留文字。
- 默认文件名使用作品名称并去掉或替换路径非法字符。目标已存在时要求确认覆盖。
- 作品归档是 `.storyarchive` 文件（ZIP），内含与数据包相同的 `work.json`、`work.sqlite`、`assets\`，含作品回收站，不含恢复点。
- 导入本应用生成的作品归档始终创建新作品和新的内部身份，允许重名，不合并、不覆盖。不导入他方工程文件，也不把 TXT / Markdown / DOCX 导入为章节。

**验收**

- 导出 Markdown 后，用文本编辑器打开能看到卷章标题和基础样式对应的标记，且没有设定资料。
- 将一部含回收站条目的作品打成 `.storyarchive`，在另一作品库导入后得到可立即打开的新作品，含原正文、结构、设定、关联和作品回收站，且内部身份与原作不同。
- 导入时作品库里已有同名作品，导入仍成功，两部并存。

## 非功能保证线

在此规模内必须达标；超过可以变慢，但不能损坏数据包或拒写。

| 项目 | 保证线 |
|---|---|
| 单作正文 | 约 50 万字（按上文字数规则） |
| 单作章数 | 约 200 章 |
| 单作设定与关联 | 约 500 条 |
| 自动保存 | 不抢焦点、不跳光标与选区 |
| 作品内搜索 | 确认查询后约 1 秒内出首屏结果 |
| 打开作品 | 点开已有作品到当前章可打字，大约数秒 |
| 显示器 | 系统缩放 100%–200%；1366×768 @ 100% 可完成写作；1920×1080 @ 150% 邻侧三栏仍可写 |

## 明确不做

- 云同步、多人协作、移动端、账户与加密。
- AI 生成、润色、续写，以及任何 AI 入口或接口。
- 设定资料的完整自定义字段模板；跨作品共享、继承或同步。
- 系列管理；独立场景 / 片段层级；整书连续滚动编辑。
- 多作品或多章节标签页、多窗口。
- 写作向版本历史、章节时间线、分支稿、逐字修订追踪。
- 复杂排版；正文插图、表格、行内批注、隐藏备注。
- 角色数值属性、库存或专用关系字段；情节点 / 节拍实体。
- 正文选中文字自动建关联或插入可见标记。
- 跨作品搜索、正则搜索、批量替换；复制章节、批量结构操作。
- 每日目标、写作统计图表。
- 完整地图绘制器、每地点单独附图、可编辑路线规划、地图上绘制通用关联。
- 为故事线 / 角色 / 地点 / 设定各建独立分区主页。
- 导入 Scrivener、Word 或其他软件工程文件；导入 TXT / Markdown / DOCX 为章节。
- 自动更新器。
- 作品回收站不承担整部作品删除（整书删除走作品库回收区）。
