# 07: 地点标记

**What to build:** 作者能在总图上单击为未定点地点打标记、拖动改位置，再次打开位置仍在；清图后标记全部消失，地点还在树里。

**Blocked by:** 03 作品总图底图

**Status:** ready-for-agent

- [ ] 往库里写第一个标记之前，坐标相对底图固有宽高归一化；点击在图像空间计算，显示按 contain 回投
- [ ] 100% 与 150% 缩放各拖一次，再换一张不同比例的图打开，标记不漂
- [ ] 单击可为未定点地点打上标记；未打标记的地点只出现在地点树中
- [ ] 清除总图后地点仍在地点树，标记全部消失
