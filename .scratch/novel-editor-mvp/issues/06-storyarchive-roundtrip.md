# 06: 作品归档导入导出

**What to build:** 作者能把一部作品打成 `.storyarchive`，在作品库里导入后得到可立即打开的新作品，内部身份不同，允许与原作重名并存。

**Blocked by:** 01 收口关联与命令面板

**Status:** ready-for-agent

- [ ] 归档是 ZIP，内含与数据包相同的 `work.json`、`work.sqlite`、`assets\`，含作品回收站，不含恢复点
- [ ] 导入始终创建新作品和新的内部身份，不合并、不覆盖
- [ ] 作品库已有同名作品时导入仍成功，两部并存
- [ ] 导入后含原正文、结构、设定、关联和作品回收站
