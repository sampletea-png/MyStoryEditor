# 04: 旁路恢复点与 Backup API

**What to build:** 作者能在数据包旁看到整部作品的恢复点文件夹；应用用 Backup API 创建它，打开中的库不能被热拷贝。本票交付创建与否决，不交付「从恢复点恢复」界面。

**Blocked by:** 01 收口关联与命令面板

**Status:** ready-for-agent

- [ ] 手动创建或触发条件达成后，数据包旁出现新的恢复点文件夹，资源管理器可见
- [ ] 恢复点含正文、结构、设定、关联、作品回收站，不内嵌其他恢复点
- [ ] 对打开中的库做热拷贝被否决，必须走 Backup API / VACUUM INTO
- [ ] 结构迁移前会先打恢复点
