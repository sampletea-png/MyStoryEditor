# 01: 收口关联与命令面板

**What to build:** 作者能在本章关联和资料卡之间建立一条双向关联，用 `Ctrl+K` 跳到章节并高亮或打开设定资料，选中正文不会建关联或插入标记。工作区里已有实现须对照验收句补齐后收口，不重开关联模型。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 本章关联把当前章与一个角色关联后，打开该角色能看到指向该章的同一条
- [ ] 同一对对象再关联一次不会出现两条
- [ ] 选中正文中的词，没有建立关联或插入标记
- [ ] `Ctrl+K` 能按章内短句跳到该章并高亮，也能按角色名打开右侧资料且正文仍在
- [ ] 两字中文名、别名走子串回退仍能命中
- [ ] 「你好，世界 Hello」字数口径为 11（前后端一致）
