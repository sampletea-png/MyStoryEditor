# 11: 从恢复点恢复

**What to build:** 作者能把一个恢复点展开成作品库里的新作品；若选择替换当前作品，须二次确认，且恢复前先为当前作品再打一个恢复点。

**Blocked by:** 04 旁路恢复点与 Backup API；08 损坏包拒绝打开

**Status:** ready-for-agent

- [ ] 默认恢复得到一部新作品，正文、结构、设定、关联与打点时刻一致
- [ ] 自动恢复点保留最近 10 个，另保留最近 7 个按日恢复点；手动恢复点不自动删除
- [ ] 「替换当前作品」须二次确认，恢复前先为当前作品再做一个恢复点
- [ ] 损坏包不能当作当前作品打开，但可提示从最近可用恢复点恢复为新作品
